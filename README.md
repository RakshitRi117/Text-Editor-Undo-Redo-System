This project presents a practical implementation of an Undo/Redo system, a feature commonly used in everyday computing. For example, the keyboard shortcuts Ctrl+Z (Undo) and Ctrl+Y (Redo) are widely recognized for reversing or reapplying actions. This project demonstrates the underlying logic using stacks to manage these operations. While not a major project, it serves as an effective demonstration of how Undo/Redo functionality is achieved in popular applications such as Microsoft Word, Excel, and various editors.
## How to Run
1. Install a C++ compiler (g++)
2. Compile: g++ practise.cpp -o texteditor
3. Run: ./texteditor
